## Question

Does a model four times larger fix E01?

## Setup

Decoder-only transformer that predicts the next frame's controller from game state and the previous input. Trained from scratch, context 256 frames. 20.7M parameters (8 × 448), rotary positions, batch 256, learning rate 5e-4, 15k steps on `yoshi-v1` (256M frames, 22.7k games).

## Judged by

Games as Yoshi against the level 9 CPU Fox with no delay (`meleebot.evaluate`). 12 games.

## Result

Validation loss 0.683 (logged to step 12,500). 1 of 12; 1.83 stocks taken and 3.83 lost per game.

## Verdict

Size alone is not the answer.
